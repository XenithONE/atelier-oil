# atelier — 油彩のアトリエ

[アトリエを開く](https://xenithone.github.io/atelier-oil/) · [UNFILED](https://xenithone.github.io/unfiled/)

絵具を混ぜ、筆跡を重ねるための、ブラウザで動く油彩専用ペイントツールです。

## アトリエにあるもの

- 平筆・丸筆・フィルバート・ペインティングナイフ・ぼかし・スポイト・スクレーパー。
- 古典的な油絵具16色と任意色。調色パレットでは2色の配合比率、最大8色の混色に対応。
- 絵具の量、乾き、混ざりやすさ、筆先角度、オイルによる希釈を調整。厚塗り・ドライブラシ・グレーズのプリセット。
- ブラシの各毛束が濡れた下の絵具を拾い、筆に色を持ち越します。「筆を洗う」で持ち越した色をリセットします。
- 「乾燥させる」で下塗りを固定。乾燥と絵具の削り取りも取り消せます。
- 色とは別に絵具の高さを保持し、光の方向で厚塗りの陰影を変更。リネン、コットン、滑らかな板、下地の色。
- ペンの筆圧、拡大・縮小・パン、ローカル参考画像、ブラウザ内の自動保存。
- 原寸PNGと、色・厚み・濡れ具合・設定を復元できる `.atelier` ファイル。
- 横長・縦長・正方形・1600×1200のキャンバス。最大60操作、履歴メモリー80MiB以内で取り消し。
- 同じ描画エンジンで作るオリジナル習作「風の通り道」を開いて、描き足すこともできます。

## ブラウザ操作で描く

すべての道具と数値入力に日本語のアクセシブル名があります。キャンバスは `#oil-canvas`、名前は「油彩キャンバス」です。ブラウザが表示しているキャンバスの矩形を確認し、その範囲でドラッグしてください。表示倍率に応じた座標変換はアプリが行います。

1. 「平筆」「丸筆」などを選び、絵具名のボタンから色を選びます。
2. 「筆の太さの数値」「絵具の量の数値」などへ直接数値を入力できます。
3. キャンバス上をドラッグ。色の取得は「スポイト」またはAlt＋クリック。
4. 調色は「現在の色をパレットに置く」を2色以上で押し、「混ぜる」。2色なら「左の絵具の割合」も指定できます。
5. 「作品を保存」からPNG、作品ファイルを書き出せます。

| キー | 操作 |
| --- | --- |
| B / K / S / I | 平筆 / ナイフ / ぼかし / スポイト |
| [ / ] | 筆の太さを変更 |
| Ctrl/Cmd + Z | 元に戻す |
| Ctrl/Cmd + Shift + Z / Ctrl + Y | やり直す |
| Ctrl/Cmd + S | 保存画面 |
| Space + ドラッグ | キャンバスを移動 |
| キャンバス上で矢印 | 筆の座標を移動 |
| キャンバス上でEnter | キーボード描画の開始 / 終了 |
| Shift + 矢印 | 筆を大きく移動 |

スマートフォンは画面下の「道具」「絵具」でパネルを開きます。

## 保存について

制作中の1作品をブラウザのIndexedDBへ自動保存します。通信で画像を送信しません。自動保存はブラウザと公開URLごとに独立し、データ消去やプライベートモードの終了で消える場合があります。作品を残すには `.atelier` をダウンロードしてください。新規作成やファイル読み込みは現在の作品を置き換え、履歴はリセットされます。

PNGにはキャンバスの下地と筆跡の陰影が含まれます。UI・カーソル・参考画像は含みません。作品ファイルは現在の絵具の状態を保持し、取り消し履歴と参考画像は含みません。

## 描画方式

独自のCPUラスターブラシが色・被覆率・高さ・濡れ具合を別々に保持します。各毛束が筆先前方の濡れた色をサンプリングし、[Spectral.js](https://github.com/rvanwijnen/spectral.js)のKubelka–Munk混色を行います。色の混合と被覆率の合成を分け、高さの勾配による拡散反射と鏡面反射を描画します。Pointer Eventsの筆圧と[coalesced events](https://developer.mozilla.org/en-US/docs/Web/API/PointerEvent/getCoalescedEvents)に対応し、非対応ブラウザでは通常のpointermoveを使用します。

これは油彩の見え方と操作感を近似するペイントエンジンです。実際のメーカーの測定顔料、流体計算、実時間の化学的乾燥は再現しません。乾燥は明示的な操作です。絵具の重なりを1つの物理キャンバスとして扱い、独立したデジタルレイヤーはありません。

## 開発と公開

Node.js 22.12以降を使います。

```sh
npm ci
npm run dev
npm test
npm run build
```

React + TypeScript + Vite。静的ファイルのみで動作し、APIキーやサーバーは不要です。フォントと混色ライブラリも一緒に配信します。GitHub Pagesの公開元はGitHub Actionsです。`main`へのpushでテスト・ビルド後に公開します。

`design/concept.png`は内蔵Image Genで作成したUI設計参考です。`design/design-system.md`に生成概要と実装方針、`docs/verification.md`に検証結果を記載しています。画面の絵具と習作は画像を背景に貼ったものではなく、実際の油彩エンジンで描いています。
